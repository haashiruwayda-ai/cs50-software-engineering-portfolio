# CS50 Introduction to Computer Science Portfolio
This repository contains my code files from Harvard University's CS50 course. It shows the programs I have completed while learning software development.

## Projects Included

### Cash (/cash)
* Description: A command line program written in C that calculates the minimum number of coins needed to give a customer change.
* Concepts: Loops and optimization logic.

### Mario (/mario-less)
* Description: A console program that uses nested loops to generate a visual pyramid structure in the terminal based on user input size.
* Concepts: User input validation and nested loops.

### Scrabble (/scrabble)
* Description: A program that calculates the score of two words using standard Scrabble point values to determine the winner of a game.
* Concepts: Arrays, character manipulation, and scoring logic.

Language Used: C
Environment: Linux and VS Code Codespaces
